\# Caso de estudio: Robot MELFA de 6 GDL



\## Descripción



Este proyecto parte de un notebook académico

de cinemática de un robot industrial MELFA

de seis grados de libertad.



\## Problema



El notebook reúne diferentes responsabilidades:



\- Transformaciones homogéneas.

\- Visualización 3D.

\- Cinemática directa.

\- Cinemática inversa.

\- Ejemplos numéricos.



Tener todo en un único notebook dificulta

reutilizar, mantener y probar el código.



\## Objetivo



Convertir el notebook original en un proyecto

Python organizado, documentado y verificable.



\## Estrategia



1\. Conservar el notebook original.

2\. Organizar la documentación.

3\. Separar funciones reutilizables.

4\. Incorporar pruebas básicas.

5\. Registrar los cambios mediante Git.
