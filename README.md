\# Cinemática de robot MELFA de 6 GDL



\## Descripción

Este proyecto organiza un notebook académico de cinemática de un robot industrial MELFA de seis grados de libertad.



\## Objetivo

Aprender a utilizar Git y GitHub para desarrollar un proyecto técnico organizado, documentado y verificable.



\## Contenido

El proyecto parte de un notebook con transformaciones homogéneas, visualización 3D, cinemática directa e inversa.



\## Organización

\- `notebooks/`: notebook académico original.

\- `src/`: código Python reutilizable.

\- `docs/`: documentación técnica del proyecto.



\## Estado

Proyecto en construcción.
